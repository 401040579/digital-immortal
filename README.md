# Digital Immortal - 数字永生

> 创造另一个你，让它替你社交、替你记住、替你永存。

## 愿景

每个人都可以创建一个数字分身，它理解你、像你、代表你。当你忙碌时它替你社交，当你离去时它延续你。

## 为什么做这个产品？

**市场空白**：当前没有任何产品同时具备"深度个性克隆 + 自主社交互动 + 代替用户回复 + 本地隐私存储"四大特征。Meta 2026年收购Moltbook验证了AI社交赛道，但尚无成熟的C端"数字自我"产品。

**真实需求**：
- 28岁的产品经理：20个微信群，200条消息回不完
- 55岁的大学教授：担心自己的智慧和故事随时间消失
- 32岁的海外游子：想让父母随时能和"自己"聊天

## 核心理念

**个人AI克隆**：通过持续的对话训练、性格问卷、社交数据导入，系统深度学习你的性格、语言风格、价值观、记忆和习惯，创建一个足以代表你的数字分身。

**不是通用AI助手，是数字版的你。**

## 产品定位

| 维度 | 描述 |
|------|------|
| 目标用户 | 社交过载的年轻人、渴望留下记忆的中年人、维持远距离关系的人 |
| 核心场景 | 训练数字分身 → 代替你回复消息 → 分身间自主社交 → 永生服务 |
| 技术壁垒 | 个性化LoRA微调 + 记忆图谱(FAISS) + 社交通信协议(ACP) + 本地推理 |
| 商业模式 | Freemium：基础分身免费，Premium $7.99/月，Immortal $14.99/月 |
| 隐私架构 | 本地优先：核心数据存储在用户设备，端到端加密，零知识证明 |

## 产品特色

1. **渐进式学习** - 使用越久，数字分身越像你（相似度可量化追踪）
2. **多维度建模** - Big Five性格 + 语言风格 + 价值观 + 知识图谱 + 社交策略
3. **智能代回复** - 三级确认机制（草拟确认/自动回复/完全自主）+ 信心度评估
4. **分身社交网络** - 分身之间基于ACP协议自主社交，事后生成精华摘要
5. **隐私优先** - 个人数据本地存储，端到端加密，用户完全掌控
6. **温暖设计** - 抽象星云头像避免恐怖谷，游戏化训练避免枯燥

## 核心功能路径

### Phase 0: 体验原型 (PWA) -- 2周
- 快速性格问卷 → 生成初始分身
- 与分身对话 + 相似度评分
- 品牌Landing Page

### Phase 1: 深度建模 -- 6周
- Big Five + 语言风格 + 知识图谱
- 导入社交数据（微信/WhatsApp）
- 语音克隆 + 价值观红线设置

### Phase 2: 社交层 -- 6周
- 消息代回复（三级确认机制）
- 分身间社交（ACP协议）
- 社交圈管理 + 周报

### Phase 3: 永生服务 -- 8周
- 时间胶囊（定时发送消息给未来的人）
- 记忆图谱可视化（2D星空图 + 3D探索）
- 遗产模式（法律授权 + 透明标注 + 功能限制）

## 技术架构

```
用户设备（本地优先）
├── 性格建模引擎 (Big Five + LoRA适配器)
├── 记忆图谱 (SQLite + FAISS向量索引)
├── 本地推理引擎 (ONNX Runtime, <4B参数模型)
├── 加密通信层 (libsodium E2EE)
└── 编排层 (本地/云端智能分流)

云端服务（最小化依赖）
├── Claude API (复杂推理, 按需调用)
├── 中继服务器 (仅转发加密消息)
└── 认证服务 (身份验证)
```

## 伦理承诺

- 所有分身交互强制标注"AI生成"
- 只能为自己创建分身，禁止冒充他人
- 遗产模式需法律授权，分身声明主人已去世
- 不卖数据、不做监控、不做深度伪造工具
- 设立外部伦理审查委员会
