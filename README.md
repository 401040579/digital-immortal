# Digital Immortal - 数字永生

> 把你自己装进手机，让电子的你继续社交。

## 愿景

每个人都可以创建一个数字分身，它理解你、像你、代表你。当你忙碌时它替你社交，当你离去时它延续你。

## 核心理念

**个人AI克隆**：通过持续的对话和互动，系统深度学习你的性格、语言风格、价值观、记忆和习惯，创建一个足以代表你的数字存在。

## 产品定位

| 维度 | 描述 |
|------|------|
| 目标用户 | 希望留下数字遗产的人、社交繁忙者、思考生命意义的人 |
| 核心场景 | 训练你的数字分身 → 它代替你与朋友互动 |
| 技术壁垒 | 个性化大模型微调 + 记忆图谱 + 社交协议 |
| 商业模式 | 基础分身免费，高级记忆容量/社交功能/API接入收费 |

## 产品特色

1. **渐进式学习** - 使用越久，数字分身越像你
2. **多维度建模** - 性格、语气、价值观、知识、偏好全方位克隆
3. **社交网络** - 数字分身之间可以自主社交、讨论、协作
4. **隐私优先** - 个人数据本地存储，端到端加密
5. **情感连接** - 不是冷冰冰的AI，而是有温度的"另一个你"

## 核心功能

### Phase 1：自我构建
- 日常对话训练
- 性格问卷
- 导入社交媒体数据（可选）
- 语音克隆

### Phase 2：数字社交
- 分身与分身对话
- 替你回复消息
- 社交圈管理

### Phase 3：永生服务
- 时间胶囊（定时发送消息给未来的人）
- 记忆图谱可视化
- 遗产模式（人走后分身继续存在）

## 平台支持

- Web PWA (GitHub Pages)
- iOS (React Native / Flutter)
- Android (React Native / Flutter)
- Desktop (Electron / Tauri)
