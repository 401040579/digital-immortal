# Digital Immortal - 产品设计文档

## 1. 产品概述

Digital Immortal 让每个人都能创建一个深度学习自己的AI分身。这个数字分身存储在用户手机上，能像你一样思考、说话、社交。它不是一个简单的聊天机器人，而是一个持续进化的"数字你"。

**产品核心假设：**
- 人们愿意花时间"训练"一个像自己的AI
- 数字分身之间的社交是有趣且有价值的
- "代替用户回复消息"是一个真实的刚需场景
- 用户愿意为"数字永生"付费

## 2. 用户画像

- **痛点**：父母相继去世后意识到很多故事和智慧没有被记录，担心自己也会如此
- **期望**：一个能像自己一样和后代交流的数字存在
- **付费意愿**：高，愿意一次性付费或年费
- **使用频率**：每周2-3次，偏向深度对话

- **典型人物**：小美，32岁，留学海外，父母在国内
- **痛点**：时差12小时，想跟父母保持联系但时间对不上

## 4. 消息代回复确认机制 (详细设计)

### 4.1 权限等级

```
Level 0 - 禁止代回复
  适用于：敏感联系人（老板、法律相关等）
  行为：分身不参与任何回复

Level 1 - 仅草拟（默认）
  适用于：大多数朋友
  行为：分身草拟回复 → 推送给用户确认 → 用户修改/确认 → 发送
  超时策略：30分钟未确认则提醒用户，不自动发送

Level 2 - 自动回复 + 事后审核
  适用于：非常熟悉的朋友、社交群
  行为：分身自动回复 → 用户事后查看 → 可撤回（5分钟内）
  限制：单日自动回复上限50条，超出后降级为 Level 1

Level 3 - 完全自主（仅限分身间社交）
  适用于：对方也是数字分身
  行为：分身与分身自由对话，事后生成摘要
  限制：不得涉及财务、法律、健康等敏感话题
```

### 4.2 信心度机制

分身在生成每条回复时计算一个"信心度"(0-100)：
- **90-100**：非常确定这是用户会说的话 → 按权限等级正常处理
- **70-89**：比较确定 → 按权限等级正常处理，标记为"中等信心"
- **50-69**：不太确定 → 无论权限等级，强制降为 Level 1（需确认）
- **0-49**：无法判断 → 拒绝回复，通知用户亲自处理

### 4.3 学习闭环

```
分身草拟回复 → 用户修改 → 差异分析引擎 → 更新人格模型
                  ↓
           修改类型分类：
           - 语气调整（温度参数微调）
           - 内容纠正（知识图谱更新）
           - 风格偏差（语言模型微调）
           - 红线触碰（添加新约束规则）
```

## 5. 数字分身社交协议

### 5.1 分身身份认证

每个分身拥有唯一的数字身份，包含：
- **分身ID**：基于用户公钥生成的唯一标识
- **可信度评分**：基于训练时长、数据量、用户活跃度计算
- **版本号**：人格模型的版本，便于追踪分身"成长"
- **认证状态**：未认证 / 基础认证（邮箱）/ 实名认证（身份证）

### 5.2 社交握手协议

```
分身A发起对话请求 → 分身B检查权限设置
→ 双方交换"社交名片"（包含可公开信息摘要）
→ 协商对话参数：
  - 允许话题范围
  - 对话时长限制
  - 信息披露等级
  - 是否实时通知本人
→ 对话开始，双方遵守协商参数
→ 对话结束，各自生成摘要发给本人
```

### 5.3 分身间通信规则

- **异步优先**：分身间对话不要求实时，可以像邮件一样异步
- **话题守护**：如果对话偏离允许话题范围，分身主动拉回或终止
- **情感边界**：分身不得代表用户表达强烈情感（如表白、愤怒），这类内容需用户本人确认
- **元信息透明**：每条消息附带元数据（信心度、信息来源、是否涉及隐私信息）

## 8. 隐私 & 安全架构

### 原则
1. **数据本地优先** - 核心人格数据存储在用户设备上
2. **端到端加密** - 分身之间的通信全程加密
3. **用户完全控制** - 随时可以删除所有数据
4. **透明度** - 分身的每个行为都可追溯
5. **最小权限** - 分身只获取完成任务所需的最少信息

### 技术实现
- 设备端推理（小模型本地运行）
- 大模型调用时只传递必要上下文，不传用户原始数据
- 零知识证明验证分身身份
- 数据导出/删除一键完成
- 所有云端传输数据脱敏处理

## 11. 伦理考量

- 明确标注所有分身互动为"AI生成"
- 不允许分身做出用户本人不会做的承诺
- 遗产模式需要法律授权文件
- 防止恶意使用（冒充他人等）
- 定期伦理审查委员会审核
- 未成年人保护机制（详见 ETHICS_AND_LEGAL.md）
- 分身不得用于欺诈、操纵或骚扰
